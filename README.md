# VPS Buyer — Telegram-бот для покупки серверов

Бот покупает облачные серверы у провайдеров **HostVDS** и **Selectel VDS** (vds.selectel.ru) и добивается нужного IP:
если выданный IP не из выбранной подсети, сервер удаляется и создаётся новый —
пока не наберётся нужное количество серверов с нужным IP.

## Сценарий

1. `/start` → главное меню (Мои серверы, Профиль, Аккаунты, Инфо, **🛒 Купить сервер**).
2. **Купить сервер** → провайдер (HostVDS / Selectel VDS) → аккаунт (или «➕ Подключить»).
3. Бот проверяет каждую **локацию** (API отвечает, есть тарифы, зона открыта, не исчерпан лимит)
   и показывает только доступные — с флагом страны и городом. Страна определяется по геолокации
   IP-подсети локации (ipwho.is) и запоминается. Если ошиблась — поправьте вручную в `.env`:
   `REGION_NAMES=eu-west1=NL:Amsterdam,us-west=US:Silicon Valley`.
4. Бот показывает все доступные **IP-блоки** локации по трём числам — `95.182.87.#`, `94.103.80.#` …
   (IP выводятся моноширинным текстом — нажатие копирует). Можно ввести свой: `95.182.87`, `94.103` или `94`.
5. Указываете **количество** серверов, затем тариф и ОС (понятный список: «Ubuntu 22.04», «Debian 12»…,
   приложения и старые сборки — в «📦 Другие образы») → «✅ Купить».
6. **Быстрый режим (HostVDS):** IP подбирается через сетевые порты — это бесплатно и занимает ~1 с на
   десяток проверок. Если блок совпадает с подсетью, порт сразу берётся из нужной подсети. Сервер
   покупается только на порт с подходящим IP. Порты с чужими IP удерживаются до конца подбора (чтобы
   облако не выдавало их повторно) и затем удаляются.
   **Обычный режим (Selectel или если порты недоступны):** сервер создаётся, IP проверяется сразу,
   как только появляется (не дожидаясь загрузки), и чужой сервер тут же удаляется.
   Прогресс виден в сообщении, есть кнопка «⛔ Остановить».
7. В конце бот присылает список IP и root-пароли.

**☁️ Мои серверы** — список купленных серверов. Нажмите на сервер: IP, пароль root и кнопка
«🗑 Удалить сервер» (удаляет у провайдера, с подтверждением). Есть «🗑 Удалить все».

**🔄 Обновить бота** (видна только админам из `ADMIN_IDS`) — одной кнопкой скачивает свежий код
с GitHub (`git pull`), ставит зависимости и перезапускает бота. После перезапуска бот пришлёт,
что изменилось.

## Подключение Selectel VDS

Панель vds.selectel.ru → Настройки → API → создайте токен с правом на запись и отправьте боту.
API: `https://api.vscale.io/v1`, лимит 12 созданий серверов в минуту — бот сам выдерживает паузы.
У Selectel нет API со списком IP-подсетей, поэтому бот показывает подсети по IP уже существующих
серверов и запоминает все IP, которые выдаёт провайдер, — после первой покупки список станет полнее.
До этого префикс можно ввести вручную.

## Подключение аккаунта HostVDS

HostVDS работает на OpenStack (Keystone: `https://os-api.hostvds.com/identity`).
Нужны данные API из панели HostVDS (`openrc.sh`): `OS_USERNAME` (обычно `hostvds-<uuid>`, он же имя проекта)
и `OS_PASSWORD`. Сообщение с паролем бот сразу удаляет, в БД пароль шифруется (если задан `ENCRYPTION_KEY`).

## Установка на сервер — одна команда

На чистом Ubuntu/Debian сервере под root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/k9032431-cmd/Vps-Buyer/HEAD/install.sh)
```

Скрипт поставит Python и зависимости в `/opt/vps-buyer`, спросит токен бота и ваш Telegram ID,
сам сгенерирует ключ шифрования и запустит бота как службу `vps-buyer` (автозапуск после перезагрузки).

- Обновить бота — кнопка «🔄 Обновить бота» в меню или та же команда ещё раз (настройки сохраняются).
- Удалить — та же команда с `uninstall` в конце.
- Логи: `journalctl -u vps-buyer -f`, настройки: `/opt/vps-buyer/.env`.

## Запуск вручную

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # заполните BOT_TOKEN, ADMIN_IDS, ENCRYPTION_KEY
python -m bot.main
```

Тесты (с фейковым OpenStack API): `python -m tests.test_purchase`, `python -m tests.test_regions`, `python -m tests.test_servers_update`, `python -m tests.test_selectel`

## Безопасность и деньги

- `ADMIN_IDS` — обязательно укажите свой Telegram ID, иначе ботом сможет пользоваться кто угодно.
- `MAX_ATTEMPTS` — максимум созданий серверов за одну задачу (включая удалённые). У провайдера
  почасовая оплата, каждое создание/удаление может списывать деньги.
- При ошибках квоты/баланса (HTTP 402/403/413) бот сразу останавливается.

## Структура

```
bot/
  main.py          запуск, доступ по ADMIN_IDS
  config.py        настройки из .env
  db.py            SQLite: аккаунты и купленные серверы
  providers/       клиенты провайдеров: hostvds.py (OpenStack), selectel.py (api.vscale.io)
  buyer.py         цикл «купить → проверить IP → удалить/оставить»
  keyboards.py     клавиатуры
  handlers/        меню, аккаунты, покупка
```

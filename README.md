# VPS Buyer — Telegram-бот для покупки серверов

Бот покупает облачные серверы у провайдеров **HostVDS**, **Selectel VDS** (vds.selectel.ru), **Timeweb Cloud**
и **Aeza** и добивается нужного IP:
если выданный IP не из выбранной подсети, сервер удаляется и создаётся новый —
пока не наберётся нужное количество серверов с нужным IP.

## Сценарий

1. `/start` → главное меню (Мои серверы, Профиль, Аккаунты, Инфо, **🛒 Купить сервер**).
2. **Купить сервер** → провайдер (HostVDS / Selectel VDS / Timeweb Cloud / Aeza) → аккаунт (или «➕ Подключить»).
3. Бот показывает только **доступные локации** с флагом и городом (🇫🇷 Париж · eu-west2, 🇱🇻 Рига 1 · eu-north2…).
   Для HostVDS данные берутся из публичного API сайта `hostvds.com/api/regions/` (город, страна,
   «нет в наличии», «создание закрыто», техработы, свободные IPv4). Если сайт недоступен — бот сам
   проверяет каждую локацию через OpenStack, а страну определяет по геолокации IP.
   Поправить название вручную: `REGION_NAMES=eu-west1=NL:Amsterdam` в `.env`.
4. Бот показывает все доступные **IP-блоки** локации по трём числам — `95.182.87.#`, `94.103.80.#` …
   (IP выводятся моноширинным текстом — нажатие копирует). **Можно отметить несколько** (✅), есть
   «Выбрать все» и «Сбросить», а через «✏️ Свой IP» — ввести свои: `95.182.87 94.103 5`. Бот ищет любой
   из выбранных.
5. Указываете **количество** серверов, затем тариф (HostVDS: как на сайте — с ценой, без «нет в наличии»),
   **Network plan** (HostVDS: Limited / Unlimited Shared 100 Mbps · 1 Gbps · 10 Gbps, под «Все планы» —
   Dedicated; план передаётся в метаданных сервера `network_plan`, как это делает панель HostVDS) и ОС (понятный список: «Ubuntu 22.04», «Debian 12»…,
   приложения и старые сборки — в «📦 Другие образы») → «✅ Купить».
6. **Быстрый режим (HostVDS):** IP подбирается через сетевые порты — это бесплатно и занимает ~1 с на
   десяток проверок. Если блок совпадает с подсетью, порт сразу берётся из нужной подсети. Сервер
   покупается только на порт с подходящим IP. Порты с чужими IP удерживаются до конца подбора (чтобы
   облако не выдавало их повторно) и затем удаляются.
   **Обычный режим (Selectel или если порты недоступны):** сервер создаётся, IP проверяется сразу,
   как только появляется (не дожидаясь загрузки), и чужой сервер тут же удаляется.
   Прогресс виден в сообщении, есть кнопка «⛔ Остановить».
7. Каждый сервер с подходящим IP бот присылает **сразу, как только он готов** (IP, root-пароль,
   команда `ssh`) и тут же сохраняет в «Мои серверы». Итоговое сообщение повторяет IP и пароль
   **каждого** сервера. Отправка повторяется при сбоях Telegram.

**Доступ к серверам HostVDS** настраивается так же, как в панели HostVDS:
- группа безопасности `allow_all` (если её нет в аккаунте — бот создаёт её с правилами на входящие
  IPv4/IPv6). Без неё OpenStack ставит `default`, которая блокирует SSH;
- пароль root задаётся скриптом в `user_data` (хэш sha512, `chpasswd --encrypted`) — образы HostVDS
  не применяют `adminPass` от OpenStack. Пароль начинает работать примерно через минуту после запуска.

Для серверов, купленных до этого исправления, в карточке сервера есть **«🛠 Восстановить доступ»**:
добавляет `allow_all` и переустанавливает ту же систему с новым паролем (IP не меняется, диск стирается).

**☁️ Мои серверы** — список купленных серверов. Нажмите на сервер: IP, пароль root и кнопка
«🗑 Удалить сервер» (удаляет у провайдера, с подтверждением). Есть «🗑 Удалить все».

**🔄 Обновить бота** (видна только админам из `ADMIN_IDS`) — одной кнопкой скачивает свежий код
с GitHub (`git pull`), ставит зависимости и перезапускает бота. После перезапуска бот пришлёт,
что изменилось.

## Подключение Selectel VDS

Панель vds.selectel.ru → Настройки → API → создайте токен с правом на запись и отправьте боту.
API: `https://api.vscale.io/v1`, лимит 12 созданий серверов в минуту — бот сам выдерживает паузы.
У Selectel нет API со списком IP-подсетей, поэтому бот показывает подсети по IP уже существующих
серверов и запоминает все IP, которые выдаёт провайдер, — после первой покупки список станет полнее.

**🔍 Разведать доступные IP** (кнопка на шаге выбора IP для Selectel): бот проверяет 5 / 10 / 20 или
**своё число** серверов (до `SCAN_MAX`, по умолчанию 200) строго по одному: создаёт самый дешёвый
сервер → записывает его IP → удаляет → следующий. В прогрессе — найденные блоки и сколько осталось
времени; в конце — отчёт, какие блоки `a.b.c.#` выдаются и как часто. Перед запуском показывается примерная стоимость (≈ час тарифа на
каждый пробный сервер). Найденные блоки сохраняются и появляются в выборе IP.

## Подключение Timeweb Cloud

timeweb.cloud → **API и Terraform** → создайте токен и отправьте боту. API: `https://api.timeweb.cloud`.
Локации — зоны доступности (`spb-3`, `msk-1`, `ams-1`, `fra-1`, …), тарифы с ценой в месяц, пароль root
Timeweb выдаёт сам. **Выключите «Подтверждение удаления сервисов»** в настройках аккаунта — иначе на
каждое удаление нужен код из Telegram, и бот не сможет удалять серверы с чужим IP.

## Подключение Aeza

my.aeza.net → **Настройки → API** → создайте ключ и отправьте боту. API: `https://my.aeza.net/api`,
заголовок `X-API-Key`. Серверы заказываются **почасово** (`term: hour`) с баланса; удалённый сервер
стоит оплаченный час (Aeza не возвращает деньги). Цены — в евро. Пароль root бот ставит сам после
запуска сервера (`changePassword`).

У Selectel, Timeweb и Aeza нет API со списком подсетей — для них работает «🔍 Разведать доступные IP».

## Подключение аккаунта HostVDS

HostVDS работает на OpenStack (Keystone: `https://os-api.hostvds.com/identity`).
Нужны данные API из панели HostVDS (`openrc.sh`): `OS_USERNAME` (обычно `hostvds-<uuid>`, он же имя проекта)
и `OS_PASSWORD`. Сообщение с паролем бот сразу удаляет, в БД пароль шифруется (если задан `ENCRYPTION_KEY`).

## Установка на сервер — одна команда

На чистом Ubuntu/Debian сервере под root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/k9032431-cmd/Vps-Buyer/HEAD/install.sh)
```

Скрипт поставит Python и зависимости в `/opt/vps-buyer`, спросит токен бота и ваш Telegram ID,
сам сгенерирует ключ шифрования и запустит бота как службу `vps-buyer` (автозапуск после перезагрузки).

- Обновить бота — кнопка «🔄 Обновить бота» в меню или та же команда ещё раз (настройки сохраняются).
- Удалить — та же команда с `uninstall` в конце.
- Логи: `journalctl -u vps-buyer -f`, настройки: `/opt/vps-buyer/.env`.

## Запуск вручную

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # заполните BOT_TOKEN, ADMIN_IDS, ENCRYPTION_KEY
python -m bot.main
```

Тесты (с фейковым OpenStack API): `python -m tests.test_purchase`, `python -m tests.test_regions`, `python -m tests.test_servers_update`, `python -m tests.test_selectel`, `python -m tests.test_ip_select`, `python -m tests.test_network_plan`, `python -m tests.test_repair`, `python -m tests.test_access`, `python -m tests.test_scan`, `python -m tests.test_timeweb_aeza`

## Доступ по приглашению

- **Админы** — Telegram ID из `ADMIN_IDS`: всегда имеют доступ.
- **Все остальные** при `/start` видят описание бота, свой Telegram ID и кнопку
  «💬 Написать админу» (ссылка на `ADMIN_CONTACT`, по умолчанию `@oldarsi`). Остальные кнопки и
  команды для них не работают.
- Человек присылает админу свой ID, админ выдаёт доступ в **👥 Пользователи → ➕ Добавить по ID**;
  пользователь сразу получает уведомление и меню. Там же — список пользователей с доступом и
  «🚫 Забрать доступ».
- У каждого пользователя свои аккаунты провайдеров и свои серверы.

## Безопасность и деньги

- `ADMIN_IDS` — обязательно укажите свой Telegram ID. Если список пуст, бот открыт для всех.
- `MAX_ATTEMPTS` — максимум созданий серверов за одну задачу (включая удалённые). У провайдера
  почасовая оплата, каждое создание/удаление может списывать деньги.
- При ошибках квоты/баланса (HTTP 402/403/413) бот сразу останавливается.

## Структура

```
bot/
  main.py          запуск, доступ по ADMIN_IDS
  config.py        настройки из .env
  db.py            SQLite: аккаунты и купленные серверы
  providers/       клиенты провайдеров: hostvds.py (OpenStack), selectel.py (api.vscale.io),
                   timeweb.py (api.timeweb.cloud), aeza.py (my.aeza.net/api)
  buyer.py         цикл «купить → проверить IP → удалить/оставить»
  keyboards.py     клавиатуры
  handlers/        меню, аккаунты, покупка
```
